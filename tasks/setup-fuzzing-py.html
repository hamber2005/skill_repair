+- do **not** rely on activating a shell venv

+### Import patterns that survive different layouts
+
+If your repository uses a `src/` layout (e.g., `src/<pkg>/...`) or a custom package dir (e.g., `python/<pkg>/...`), add it to `sys.path` at the top of the harness **before** importing the target package.

+```python
+import os
+import sys
+
+REPO_ROOT = os.path.dirname(__file__)
+
+# Common layouts
+for rel in ("src", "python"):
+  p = os.path.join(REPO_ROOT, rel)
+  if os.path.isdir(p) and p not in sys.path:
+    sys.path.insert(0, p)

+```
