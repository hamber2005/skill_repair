+
+When producing Wigner grids for downstream evaluation, the most common failure mode is a **convention/scaling mismatch**.
+
+1) **Be explicit about the phase-space convention (`g` / `hbar`)**
+
+QuTiP’s `wigner` uses a scaling parameter `g` where `hbar = 2/g^2` (docstring). If your reference/verification expects the default `hbar=1` convention, you must keep `g=np.sqrt(2)` (QuTiP default). If a reference uses a different convention (e.g., `hbar=1/2`), you must adjust `g` accordingly.
+
+```python
+xvec = np.linspace(-6, 6, 1000)
+pvec = np.linspace(-6, 6, 1000)
+
+# Default QuTiP convention: g=sqrt(2) => hbar=1
+W = wigner(rho, xvec, pvec, g=np.sqrt(2), method='clenshaw')
+```
+
+2) **Handle `method='fft'` return type differences**
+
+In some QuTiP versions, `wigner(..., method='fft')` may return a **tuple** (e.g., `(W, something)`), not just an array. Always guard this before further NumPy operations or saving.
+
+```python
+W = wigner(rho, xvec, pvec, method='fft')
+if isinstance(W, tuple):

+```
+
+3) **Verify normalization by numerical integration on your grid**
+
+Many verifiers treat the Wigner grid as a density over phase space and check:
+
+\[\int W(x,p)\,dx\,dp \approx 1.\]
+
+On a uniform grid, check via the cell area:
+
+```python
+# For linspace endpoints included:
+dx = (xvec[-1] - xvec[0]) / (len(xvec) - 1)

+```
